# NiceToHave roadmap

Planning for NiceToHave. Two kinds of note, one relation between them:

- **[[Ideas]]** are raw capture. One per idea, annoyance, bug or dream. They are never worked from directly.
- **[[Builds]]** are units of work handed to a Claude Code session. One per session. The prompt that starts the session lives in the note body, and the note names the ideas it covers.

Specs that builds start from live in `Research/`.

## To browse

**[[Build queue.base]]** and **[[Idea backlog.base]]** are the interactive views: sortable,
filterable, always live off the notes' own properties.
